# 01. 가설 사전등록 (Pre-registration)

> **이 문서는 어떤 실증 결과도 확인하기 전에 작성·커밋되었다.**
> 커밋 타임스탬프가 사전등록의 증거이며, 이후 수정은 별도 커밋으로
> 변경 이력과 사유를 남긴다. 결과를 본 뒤 가설이나 기준을 바꾸지 않는다.

---

## 1. 연구 질문

한국 주식시장에서 개별 종목의 수요곡선은 우하향하는가?
그리고 그 기울기(가격 비탄력성)는 **유통주식 희소성**에 따라
체계적으로 달라지는가?

## 2. 이론적 배경

Shleifer(1986)는 S&P500 지수 편입이 펀더멘털과 무관한 수요 충격임을
이용해 주식 수요곡선이 우하향함을 보였다. Gabaix–Koijen의
Inelastic Markets Hypothesis는 이를 승수(multiplier)로 정량화한다.

본 연구의 기본 관계식:

```
%ΔP  ≈  (1/ζ) · ΔShares / FreeFloat
```

- `ζ` : 수요 탄력성
- `1/ζ` : 승수(multiplier). 클수록 같은 수요 충격에 가격이 크게 반응
- `FreeFloat` : 유통가능주식수

**핵심 재프레이밍**: 유통물량 희소성은 밸류에이션 요인이 아니라
**증폭기(amplifier)** 이다. 본 연구는 "적정주가"를 산정하지 않는다.

## 3. 식별 전략

`ΔShares`를 내생적 주문흐름에서 추정하면 가격과 동시결정되어
식별되지 않는다. 따라서 **외생적 수요 충격**으로 지수 리밸런싱을 사용한다.

- KOSPI200 정기변경 / 수시변경
- MSCI Korea 리뷰
- FTSE GEIS 리뷰

패시브 자금은 기업가치 변화가 아니라 지수 복제 의무 때문에 매매하므로,
편입/편출은 펀더멘털과 직교하는 수요 충격으로 간주한다.

## 4. 주 가설

### H1 (수요곡선 우하향)

```
CAR_i[t0,t1] = α + β0·Shock_i + γ'X_i + ε_i
```

**H1: β0 > 0** — 수요 충격이 클수록 누적초과수익률이 크다.

### H2 (희소성 증폭) — 본 연구의 핵심

```
CAR_i = α + β0·Shock_i + β1·(Shock_i × FF_ratio_i)
            + β2·(Shock_i × log ADV_i) + γ'X_i + ε_i
```

**H2: β1 < 0** — 유통비율이 높을수록 동일 충격의 가격 영향이 작다.
즉 유통물량이 얇을수록 증폭이 크다.

여기서
- `Shock_i = ΔShares_i / FreeFloat_i`
- `FF_ratio_i = FreeFloat_i / 상장주식수_i`
- `ADV_i` : 이벤트 전 20일 평균 거래대금

### H3 (영구성 vs 일시성)

편입 효과가 장기 윈도우에서 되돌아오는가?

- 되돌림 없음 → 영구적 수요곡선 기울기 (보유 전략 함의)
- 되돌림 있음 → 일시적 가격압박 (청산 전략 함의)

두 경우의 전략 함의가 정반대이므로 반드시 분리 검정한다.

## 5. 사전 지정 사항

### 5.1 이벤트 윈도우

| 구간 | 정의 | 목적 |
|---|---|---|
| Pre | AD-20 ~ AD-1 | 프론트러닝 반영 확인 |
| Announcement | AD-1 ~ AD+1 | 정보 효과 |
| Run-up | AD+1 ~ ED-1 | 패시브 집행 선반영 |
| Effective | ED-1 ~ ED+1 | 실제 집행 |
| Post | ED+1 ~ ED+60 | 되돌림 검정 (H3) |

`AD` = 발표일(announcement date), `ED` = 실행일(effective date)

주 검정 윈도우는 **AD-1 ~ ED+1** 로 사전 고정한다.
다른 윈도우 결과는 부가 정보로만 보고하며, 주 결론을 대체하지 않는다.

### 5.2 초과수익률 산출

시장모형. 추정구간 AD-250 ~ AD-30, 시장수익률은 KOSPI 지수.
강건성 점검으로 시장조정수익률(단순 차감)을 병기한다.

### 5.3 통제변수 X

로그 시가총액, 이벤트 전 60일 수익률, 이벤트 전 20일 변동성,
업종 더미, 이벤트 연도 더미.

### 5.4 표준오차

이벤트 날짜가 겹치므로 횡단면 상관이 존재한다.
**이벤트 날짜 클러스터 표준오차**를 사용한다.

## 6. 실패 기준 (Falsification Criteria)

> 결과를 보기 전에 정한다. 이후 완화하지 않는다.

### 기각 조건

1. **H2 기각**: `β1`이 5% 유의수준에서 유의하지 않거나 부호가 양(+)
   → 희소성 증폭 가설 기각. **Track 2(얇은 유통물량)를 진행하지 않는다.**

2. **표본 부족**: 유효 이벤트 수 < 100
   → 통계적 결론을 내리지 않고 기술통계만 보고한다.

3. **강건성 실패**: 초과수익률 산출 방식(시장모형 ↔ 시장조정)에 따라
   `β1`의 부호가 뒤집히면 결과를 신뢰하지 않는다.

4. **비용 차감 후 소멸**: 후속 백테스트에서 거래비용·체결제약 반영 시
   초과수익이 사라지면 매매 적용을 중단한다.

### 진행 조건

위 1~3을 모두 통과한 경우에만 Track 2 설계로 진행한다.

## 7. 명시적 한계

1. **AUM 추정 불확실성**: 한국 지수 추종 자금 규모는 정확한 공개치가
   없다. `Shock`의 절대 크기보다 **종목 간 상대 순위**에 의존하는
   설계로 완화하나, 완전히 제거되지 않는다.

2. **FreeFloat 측정오차**: 유통가능주식수는 공시 시점 사이에 갱신되지
   않으며, 5% 미만 전략적 보유자는 포착되지 않는다. 이 오차는
   **얇은 종목에서 가장 크다** — 즉 핵심 변수에 체계적 노이즈가 있다.

3. **선반영**: 지수 편입은 룰베이스라 이벤트 드리븐 자금이 발표 전
   선반영한다. Pre 윈도우를 포함해 완화하나 완전한 통제는 불가능하다.

4. **생존편향**: 상장폐지 종목을 유니버스에 포함한다. 제외 시
   결과가 어떻게 달라지는지 병기한다.

5. **이 연구는 투자 자문이 아니다.** 통계적 관계의 존재가 실현 가능한
   수익을 의미하지 않는다. 제도 제약은 `02_data_constraints.md` 참조.
