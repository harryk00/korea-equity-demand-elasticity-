# 02. 한국 시장 제도 제약 및 데이터 한계

> 이 문서는 백테스트 결과보다 먼저 읽어야 한다.
> 아래 제약을 반영하지 않은 성과 수치는 신뢰할 수 없다.

---

## 1. 공매도 규제 이력 — 데이터 가용성의 구조적 단절

한국의 공매도 데이터는 연속적이지 않다. 규제 이력에 따라
**종목군별로 사용 가능 기간이 다르다.**

| 기간 | KOSPI200 / KOSDAQ150 | 그 외 전 종목 |
|---|---|---|
| ~2020.03.15 | 가능 | 가능 |
| 2020.03.16 ~ 2021.05 | 전면 금지 | 전면 금지 |
| 2021.05 ~ 2023.11.05 | 가능 (350종목 한정) | **불가** |
| 2023.11.06 ~ 2025.03.30 | 전면 금지 | 전면 금지 |
| 2025.03.31 ~ | 가능 | 가능 (약 5년 만) |

### 함의

**소형주·얇은 유통물량 종목(코스닥150 및 코스피200 외)의 공매도
데이터는 2025년 3월 31일 이후에만 존재한다.**

- 유효 표본: 약 17개월 (≈ 340 거래일)
- 급등은 희귀 이벤트이며 종목 간 상관(테마 동조)이 높다
  → **독립 관측치는 수십 건 수준**

### 결론

이 표본으로 공매도·대차 기반 스퀴즈 예측 모델을 학습시키는 것은
과적합이 아니라 **데이터 부재**의 문제다.
본 프로젝트는 공매도 의존 모델을 **매매 전략에서 제외**하고,
데이터 적재만 진행한다 (2~3년 후 재평가).

## 2. 시장경보제도 — 예측 대상이 예측을 무효화한다

한국거래소 시장경보제도는 급등 자체에 반응하여 제약을 부과한다.
즉 **타깃 이벤트 발생이 거래 조건을 변경한다.**

### 투자경고종목 지정 시

- 위탁증거금 100% 납부 (현금)
- **신용융자 매수 금지**
- 대용증권 지정 제외
- 대체거래소(NXT) 거래 제한

### 투자위험종목 격상 시

- 투자경고 상태에서 **2거래일간 40% 이상 상승** 시 격상
- 격상일 **1일간 매매거래 정지**
- 지정 후에도 3거래일 연속 상승 시 **추가 1일 정지**

### 모델 설계상 함의

1. **신용융자 피처의 역인과**
   급등 → 투자경고 지정 → 신용융자 매수 금지.
   즉 신용잔고는 급등을 예측하는 것이 아니라, 급등 이후
   **기계적으로 차단된다.** 이 구조를 통제하지 않으면 모델이
   역방향 인과를 학습한다.

2. **급등 후반부의 체결 불가**
   백테스트가 10일 홀딩 +45%를 기록해도, 경로 중간에 거래정지가
   포함되면 실현 불가능하다.

3. **제도 자체의 변경**
   2026년 4월, 거래소는 시장경보 지정 종목의 위탁증거금 100%
   징수 의무를 면제하는 규정 개정을 예고했다(시행 예정 5월).
   → 표본 기간 내 **레짐 변화가 추가로 존재**한다.

## 3. 가격제한폭 및 변동성완화장치 — 체결 가능성 문제

### 상한가 (±30%)

상한가 도달 시 매도 호가가 소멸한다.
모델이 "익일 +30%"를 정확히 예측해도, 대기 물량 뒤에서
체결되지 않으면 수익은 0이다.

> **역설: 가장 정확한 예측일수록 가장 체결이 어렵다.**

### 변동성완화장치 (VI)

급격한 가격변동 시 단일가매매로 전환된다.
진입·청산 타이밍이 통제 불가능해진다.

### 백테스트 필수 반영 사항

- [ ] 상한가 근접 시 신규 진입 불가 처리
- [ ] VI 발동 구간 체결 배제
- [ ] 거래정지일 청산 불가 처리
- [ ] 일일 거래대금 대비 진입 상한 (예: 1~3%)

## 4. Point-in-Time (PIT) 준수

한국 수급 데이터는 **공표 시차**가 있다.
결정 시점에 알 수 없었던 정보를 사용하면 룩어헤드 편향이 발생한다.

| 데이터 | 공표 시차 | 비고 |
|---|---|---|
| 투자자별 매매동향 | 장 종료 후 당일 | PIT 양호 |
| 공매도 거래 | T+1 | |
| 공매도 잔고 | T+2 | 잔고 보고 기준 |
| 대차잔고 | 마감 후 집계 | |
| 신용잔고 | 마감 후 집계 | |
| 재무데이터 | 공시일 기준 | 보고서 기준일 아님 |

**모든 피처는 실제 공표 시점 기준으로 래깅한다.**
이 처리를 하지 않으면 이후 모든 검증이 무효다.

## 5. 데이터 소스 분리

| 용도 | 소스 | 비고 |
|---|---|---|
| 시세·호가·체결, 주문 실행 | 토스증권 Open API | REST 폴링만, 웹소켓 없음 |
| 수급 (공매도/대차/신용/프로그램) | KRX 정보데이터시스템 | pykrx 커버리지 상이 |
| 유통주식수, CB/BW, 보호예수 | DART | 원문 파싱 필요 |
| 지수 편입/편출 | KRX, MSCI, FTSE 공시 | |

### 토스 API 범위 확인

제공: 인증(OAuth2), 시세·종목정보(현재가·호가·체결·캔들·종목마스터),
계좌·자산, 주문.

**미제공: 공매도·대차·신용·프로그램 수급 데이터.**
→ 토스는 **실행(execution) 계층**이며 피처 소스가 아니다.

### 아키텍처 제약

REST 폴링만 가능하고 호출 한도가 있으므로 전 종목 실시간 감시는
불가능하다. **2단계 구조가 강제된다:**

1. EOD 광범위 스크리닝 (KRX 데이터 기반)
2. 후보 20~50종목만 장중 폴링 (토스 API)

## 6. 체결강도 처리 방침

체결강도는 과거 시계열 복원이 불가능하다 (틱/호가 데이터 필요).
실시간으로는 토스 체결 데이터로 계산 가능하나,
웹소켓 부재로 폴링 간격 내 체결을 누락하여 편향이 발생한다.

**방침: 백테스트 불가능한 피처는 모델에 포함하지 않는다.**
체결강도는 모델 피처가 아니라 **진입 타이밍 필터**로만 사용한다.

## 7. 벤치마크 설정 오류 주의

본 연구의 관심 유니버스(얇은 유통물량 · 고변동성 · 고회전율)는
학술 문헌의 **복권형 주식(lottery-like stocks)** 정의와 거의 일치한다.
이 그룹은 여러 시장에서 평균적으로 음(-)의 초과수익이 보고된다.

따라서 성과 평가 기준은 절대수익이나 무위험수익률이 아니라
**동일 특성 종목 동일가중 바스켓**이어야 한다.

> 구조적으로 기대수익이 낮은 바구니에서 종목을 고르는 게임이므로,
> 모델은 그 바구니 자체를 이겨야만 의미가 있다.

## 8. 생존편향

얇은 유통물량 종목은 관리종목 지정·상장폐지 위험이 구조적으로 높다.
"현재 상장중" 유니버스를 사용하면 살아남은 종목만 조건부로 관측된다.

**상장폐지 종목을 유니버스에 포함하고, 상장폐지를 큰 음의 수익으로
라벨링한다.** 제외 시 결과 차이를 병기한다.
